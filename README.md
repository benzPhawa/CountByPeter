## Installation

Create Virtual Environment

```bash
python -m venv .venv
```

Windows

```bash
.venv\Scripts\activate
```

Install Packages

```bash
pip install -r requirements.txt
```

Run

```bash
python run.py
```

Open Browser

```
http://127.0.0.1:8000
```
